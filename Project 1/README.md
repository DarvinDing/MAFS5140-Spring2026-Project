# Mini Project 1 – Momentum Strategy with Z‑Score Filter & Volatility Scaling

## Overview

This strategy implements a **rank‑based momentum** approach with a statistical significance filter (z‑score / t‑statistic) and volatility scaling. It selects assets that have shown statistically strong upward momentum over a lookback period, then allocates capital inversely proportional to their recent volatility.

**Key features:**
- Rolling window of historical close prices
- Z‑score (t‑statistic) of mean return as momentum strength measure
- Filter assets with z‑score above threshold (default 1.0)
- Select top K assets by z‑score
- Weight assets inversely by their volatility
- Keep a cash buffer (default 10%)
